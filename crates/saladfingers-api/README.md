# saladfingers-api

A hand-written, typed client for the [SaladCloud](https://salad.com) public REST API
and its S4 storage, used by the
[`saladfingers`](https://crates.io/crates/saladfingers) CLI.

Part of saladfingers: <https://github.com/purefunsolutions/saladfingers>.
